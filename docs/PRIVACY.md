# 数据、记忆与安全边界

## 数据去向

| 数据 | 应用本地持久化 | API 发送 |
| --- | --- | --- |
| 原始互动麦克风 PCM | 否，内存队列 | Qwen ASR |
| ASR 中间转写 | 否，浏览器/桥接内存 | 由 ASR 返回 |
| 最终消息与回答 | SQLite | 当前轮及必要上下文发给对话模型 |
| 摄像头 JPEG | 不保存图像，只记指纹 | 按需发给 Qwen 视觉模型 |
| 家长确认档案 | 本地 JSON 与 SQLite 版本 | 与当前问题相关的字段 |
| 合成台词与音频 | 成功完整 WAV 缓存 | 新台词发给 Qwen TTS |
| 声音克隆参考样本 | 家长自行配置的私有文件 | 仅授权创建音色操作中上传 |
| API Key | 私有 `.env` 或进程环境 | 对应供应商鉴权，不发浏览器 |

本地优先不等于完全离线，也不代表供应商一定不保留请求。供应商日志、保留策略与跨区域处理应由使用者核对相应服务条款。

## SQLite 数据模型

- `turns`：请求 ID、用户文本、回答、角色、场景、图片指纹、创建时间和 pending/complete/failed 状态。
- `memories`：按处理游标版本化的本地学习笔记。
- `local_observations`：规则提取的英语尝试、兴趣/反馈、作业完成自述等，保留回合来源。
- `parent_profile_versions`：家长配置的档案历史版本。
- `story_progress`：可选练习剧情进度，不是成绩证明。
- `turn_search`：FTS5 全文索引，用于相关旧回合检索。

记忆提取不调用模型，由本地规则执行。每轮读取最近 6 回合、最多 3 条检索结果及必要档案字段；并非上传完整数据库。角色无关的旧回答会过滤，公共游戏知识不当作共同经历。

规则提取可能漏记、误分类，完整保留原始转写也不意味着每次都能检索正确。孩子自述“写好了”只记录为自述，不代表图像核验或全部题目正确。取消回复保留失败回合以便恢复，不自动当作成功教学。

## 保存与恢复

SQLite 使用 WAL、外键和 `synchronous=FULL`。每轮完整回复保存后使用 SQLite backup API 生成 `backups/latest.sqlite3`，每日首份日期备份另存；随后增量整理记忆。备份失败不把已成功写入的回合当作丢失，而是返回备份状态。

没有自动删除对话的保留期限，也没有自动加密、异地同步或完整用户删除 UI。学习数据增长由家长管理。缓存有容量上限，不能与学习记忆保留策略混为一谈。

恢复前停止服务，备份当前整个私有目录，然后用有效的 SQLite 备份替换数据库；不要在运行中直接覆盖主数据库或仅复制一个活动 `.sqlite3` 文件而忽略 WAL。音色、API 配置、参考音频和私有图像不在 SQLite 备份里，需单独恢复。恢复后检查数据库完整性和角色音色，再进行互动。

## 威胁模型

当前保护包括回环绑定、Host/Origin 校验、进程令牌、静态资源白名单、CSP、请求大小限制与不落盘原始媒体。没有面向互联网的账户、设备配对、密钥加密或细粒度权限体系。

同一 Windows 账户下的恶意软件仍可能读取 `.env` 和 SQLite；有本机访问能力的软件可访问健康接口取得会话令牌。因此不要把这个令牌称作抵御本机攻击的认证机制。建议开启系统磁盘加密、限制账户权限、保护备份并更新浏览器。

上传日志前脱敏。`window.myprofessorAudioDiagnostics` 仅保存最近少量错误分类与队列大小；`window.myprofessorLatency` 保存内存中的时间点。二者不需要原始音视频，但其他日志和导出仍应人工检查。
